# 03 - 中间件与公共层

## 1. 中间件执行顺序

`router/router.go` 中的完整顺序：

```
全局:  DrainBody → BodyLimit → metrics → Recovery → Logger → Cors → Tenant
受保护组: Auth → CSRF → CasbinAuth → OperationLog
公开接口: RateLimit（按接口配置）
特例:     POST /api/v1/pay/order → Idempotency；/uploads → UploadSecurity
```

> 注意：gin 的**组中间件先于路由级中间件执行**。不要用路由级中间件 `c.Set()` 传权限码，会导致组级 `CasbinAuth` 读不到值而整体跳过校验（历史踩坑）。

## 2. 中间件逐一说明（`internal/middleware/`）

| 文件 | 中间件 | 职责要点 |
|------|--------|----------|
| `drain_body.go` | `DrainBody` | 排空/限流请求体读取，配合 `BodyLimit` 在最前置限制大 body 攻击；`DrainBodyFromConfig` 从配置读取上限 |
| `body_limit.go` | `BodyLimit` / `BodyLimitFromConfig` | 超过 `server.max_body_size` 直接 413；错误信息用 `humanSize` 可读化 |
| `recovery.go` | `Recovery` | panic 恢复 → 500 + zap 记录堆栈；`sanitizeRequest` 脱敏请求描述 |
| `logger.go` | `Logger` | 请求访问日志（方法、路径、状态码、耗时） |
| `cors.go` | `Cors` | 开发模式允许所有来源；生产必须 `cors.allow_origins` 白名单；`AllowCredentials` 只配白名单 |
| `tenant.go` | `Tenant` | 从 JWT claims 提取 tenantID 写入上下文（**禁止从 Header/Query 读取**），供 `common.TenantIDFrom` 使用 |
| `auth.go` | `Auth` | 解析 token（`extractToken` 支持 header / Cookie 双通道，记录来源）→ 校验签名与 issuer → **Redis 吊销检查 `IsTokenRevoked`，失败 fail-closed** → 写入 userID/username/tenantID/deptID；`canAccessWithoutTenant` 允许平台角色无租户；`RequireAdminRole` 额外要求 admin |
| `csrf.go` | `CSRF` | Cookie 通道（`token_transport` 含 cookie）时强制 double-submit：对比 `X-CSRF-Token` 头与 Cookie；`isSafeMethod` 放行 GET/HEAD/OPTIONS。SameSite=Lax 是主防线，此为纵深防御 |
| `casbin.go` | `CasbinAuth` | `c.FullPath()` → 权限登记表查权限码 → `resolveRoleCodes`（Redis 缓存 `rbac:roles:<tenant>:<user>`，经 `RoleResolver` 注入，失败 fail-closed）→ 逐角色 `Enforce(sub=角色code, dom=*, obj=路径, act=方法)`；未登记 → 403。辅助：`HasAdminRole`、`SyncPoliciesFromRoleMenus`（策略同步）、`ClearRoleCache`、`OperatorHoldsPermissions`（授权收敛） |
| `casbin_adapter.go` | — | 自研 GORM 适配器（`casbin_rule` 表的 Load/Save/Add/Remove 系列），不依赖官方 adapter |
| `permission.go` | — | 路由权限登记表：`RegisterPermission(method, fullPath, code)`、`routePermission` 查询、`IsRegisteredPermission` |
| `operation_log.go` | `OperationLog` | 异步写操作日志（经 `SetOperationLogWriter` 注入的 writer，避免依赖模块层）；**请求体自动脱敏** `sanitizeRequestBody`：`sensitiveNameFragments` 匹配 password/secret/token/privatekey/accesskey/apiv3key/pem 等，并识别 `{"key":"secret_key","value":...}` 分离结构；非 JSON 不记录；整体 2000 字截断；`resolveTitle` 把路由路径映射为中文标题 |
| `ratelimit.go` | `RateLimit` / `RateLimitWithStore` | Redis 滑窗计数（`IncrWindow` 原子"加一并首次设 TTL"）；身份维度 `rateLimitIdentity`（IP/账号）；配置：login 10/min、refresh 30/min、captcha 30/min、pay-notify 120/min |
| `idempotency.go` | `Idempotency` | 幂等中间件：客户端带 `Idempotency-Key` → Redis `SetNX` 占位 → `captureResponseWriter` 捕获响应，重复请求直接 `replayIdempotent` 回放缓存响应。挂于 `POST /pay/order` |
| `static.go` | `UploadSecurity` | `/uploads` 静态目录补安全头：CSP 沙箱（防 SVG XSS）、禁嗅探、`Content-Disposition` 等 |

## 3. 公共层 `internal/common`

### 3.1 统一响应（`response.go`）

```go
common.Success(c, data)
common.SuccessWithPage(c, list, total, page, pageSize)
common.Error(c, code, message)            // Controller 自身错误（绑定失败等）
common.ErrorWithHttpStatus(c, http, code, message)
common.Unauthorized(c, "未登录")
common.Forbidden(c, "无权限")
common.FailWith(c, err)                   // Service 错误的唯一出口
```

禁止 `c.JSON()` 直接返回业务数据。

### 3.2 错误语义（`bizerror.go` + `errors.go`）

| 错误来源 | 构造方式 | 业务码 | 对外文案 |
|----------|----------|--------|----------|
| 业务校验失败 | `NewBizError("...")` / `NewBizErrorf` | 400 | 原文透出 |
| 目标不存在 | `NewNotFoundError` | 404 | 原文透出 |
| 未登录 | `NewUnauthorizedError` | 401 | 原文 |
| 无权限 | `NewForbiddenError` | 403 | 原文 |
| DB/IO/第三方 | 原样 `return err` | 500 | **通用文案**，细节只进日志 |

关键辅助：

- `NotFoundOrErr(err, "XX不存在")` —— 单条查询必用，把 `gorm.ErrRecordNotFound` 转成 404 而非 500；
- `AsBizError(err)` / `IsBizError(err)` —— `FailWith` 内部据此选码。

### 3.3 分页与上下文（`page.go` / `context.go` / `context.go`）

- `BindPage(c, req)`：绑定 query 分页参数；
- `NormalizePageParams(page, pageSize)` + `MaxPage`：防超大 page/pageSize 溢出；
- `TenantIDFrom / GetTenantID / GetCurrentUserID / GetCurrentUsername / GetDeptID`：从上下文取值；
- `GetUintParam / GetPageInfo / NormalizeIP`。

### 3.4 租户（`tenant.go`）

```go
func TenantScope(db *gorm.DB, tenantID uint) *gorm.DB
```

- `tenantID != 0` → 加 `tenant_id = ?` 过滤；
- **`tenantID = 0` → 不过滤**（平台级账号）。因此漏传 tenantID 会静默退化为全表查询，造成跨租户泄漏 —— Repository 签名强制带 tenantID 就是防这个（`internal/conventions` 有机械测试）。

### 3.5 其他工具

| 文件 | 函数 | 用途 |
|------|------|------|
| `softdelete.go` | `FreedUniqueValue(value, id, maxLen)` | 删除前改写唯一字段为 `_del_<id>`，释放唯一索引占用（**必须显式先查后改，不用 BeforeDelete 钩子**） |
| `tree.go` | `BuildTree[T] / BuildTreeForest[T]` | 泛型树构建（菜单、部门） |
| `like.go` | `EscapeLike(s)` | 转义 `% _ \` 防 LIKE 注入 |
| `collection.go` | `UniqueNonZeroIDs` | ID 去重去零 |
| `model.go` | `BaseModel / TenantBaseModel` | 基础字段与租户字段 |
| `constants.go` | — | 业务常量 |

## 4. Redis 缓存层（`internal/cache/redis.go`）

`Init()` 启动即连，**失败直接退出**（强依赖）。包级函数 `Set/Get/GetString/Del/Exists/SetNX/Incr/Expire/TTL/IncrWindow/SAdd/SRem/SMembers/DelByPrefix`。

### Key 体系

| Key 模式 | 类型 | 用途 |
|----------|------|------|
| `refresh_token:<token>` | string + TTL | Refresh Token 存储（7 天） |
| `refresh_token:user:<userID>` | Set | **用户维度索引**，改密/禁用/登出批量吊销的前提 |
| `user:token_revoked:<userID>` | string | 用户级吊销标记（fail-closed 检查） |
| `token:blacklist:<token>` | string + TTL | Access Token 黑名单（登出） |
| `login:fail:ip:<ip>` / `login:fail:account:<name>` | string + TTL | 登录限频计数（SETNX 建键，5 次锁 15 分钟） |
| `captcha:<id>` / `captcha:verified:<token>` | string + TTL | 验证码答案 / 登录一次性凭证（5 分钟） |
| `rbac:roles:<tenant>:<user>` | string + TTL | 角色码缓存 |
| `ratelimit:*` | string + TTL | 通用滑窗限频 |
| `idempotency:*` | — | 幂等占位与响应缓存 |
| `member:no` | string | 会员号发号器 |

辅助函数：`RefreshTokenKey / RefreshTokenSetKey / UserTokenRevokedKey / RevokeToken / IsTokenRevoked`。

## 5. 其他基础设施

- `internal/database/mysql.go`：GORM 连接，`Init` 失败退出；
- `internal/logger/zap.go`：zap + lumberjack 轮转（`log.max_size/max_backups/max_age/compress`），stdout + 文件双写，父目录自动创建 + 可写性探测；
- `internal/metrics/`：Prometheus 指标，独立端口暴露（与业务端口分离）；
- `internal/authcookie/`：Cookie 通道常量（access/refresh cookie 名、CSRF cookie、SameSite/Secure 设置）；
- `internal/conventions/`：架构约定的**机械化测试**（如断言所有 Repository 方法签名含 tenantID、禁止跨模块引用等），`go test` 即校验；
- `internal/testsupport/`：测试辅助（临时 DB、mock 等）；
- `config/casbin/model.conf`：RBAC 模型定义，`[request_definition] r = sub, dom, obj, act`，匹配函数支持通配。
