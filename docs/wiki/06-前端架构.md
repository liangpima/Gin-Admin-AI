# 06 - 前端架构（web/）

Vue 3.5 + TypeScript 5.7 + Vite 6 + Element Plus 2.9 + Pinia 2.3，Node ≥ 22。

## 1. 目录结构

```
web/src/
├── api/            # 20 个 API 模块（与后端路由一一对应）+ axios 封装
├── components/     # 公共组件（9 个）
├── hooks/          # 组合式函数（7 个）
├── layout/         # 布局组件（侧边栏/顶栏/标签页）
├── router/         # 路由守卫 + routes/static 静态路由
├── store/modules/  # Pinia：app / permission / tagsView / user
├── utils/          # auth / format / request / sanitize / keepAlive / icons
└── views/          # 页面（login、dashboard、system/*、payment、member、settings/*、error）
```

## 2. API 层（`api/index.ts`）

- axios 单例 `service` + 导出 `http` 快捷方法；
- **CSRF**：`CSRF_METHODS = ['post','put','patch','delete']` 写操作自动附带 `X-CSRF-Token` 头（与后端 double-submit 校验配对）；
- **401 单飞续期**：401 → `refreshSession()` 调 `/auth/refresh` —— **并发请求共享同一个刷新 Promise**（单飞），刷新成功后原请求重放（refreshAndReplay）；`NO_REFRESH_PATHS = ['/auth/login','/auth/refresh']` 防递归；
- `handleLogout()`：刷新也失败时清态跳登录；
- `shouldTryRefresh(config)`：按 `RetryableConfig` 判断是否可重试；
- 错误统一为 `BizError`（`code/message`），`isBizError` 判定 —— 与后端 `FailWith` 的业务码体系对接；
- `Result<T>` / `PageResult<T>` 对应 `Success` / `SuccessWithPage`。

**API 模块**：`auth` `user` `role` `menu` `dept` `post` `dict` `config` `log` `file` `agreement` `dashboard` `payment` `member` `captcha` `networkError` 等，文件与后端路由模块一一对应。

## 3. 路由与权限（`router/`）

- `routes/static.ts`：静态路由（login、404、redirect 等）；
- 守卫三段式动态路由：
  1. 未登录 → 拦到 login（token 存 Cookie，`utils/auth.ts`）；
  2. 已登录但未拉菜单 → 调 `authApi.getUserInfo` 取角色/菜单/权限 → `permission` store 生成路由并 `addRoute`；
  3. 已初始化 → 放行；
- 权限控制：菜单按钮级 v-permission（依据权限串）；
- keep-alive：`utils/keepAlive.ts` 的 `wrapForCacheName` 解决多个 `index.vue` 同名组件缓存冲突（按路由名生成唯一 cacheName）。

## 4. Pinia Store（`store/modules/`）

| Store | 职责 |
|-------|------|
| `user` | token/用户信息/登出，与 `utils/auth.ts` 的 Cookie 读写配合 |
| `permission` | 菜单树 → 动态路由生成与注册 |
| `tagsView` | 多标签页（visitedViews / cachedViews） |
| `app` | 侧边栏折叠、设备尺寸、主题（配 `useTheme`）、面包屑等全局 UI 态 |

## 5. Hooks（`hooks/`）

| Hook | 用途 |
|------|------|
| `useCrud` | CRUD 页面通用逻辑：分页、搜索、对话框开关、删除确认（各管理页复用） |
| `useDict` | 数据字典拉取与缓存（对接 `sys_dict`） |
| `useResponsive` | 设备断点状态（mobile <768 / tablet 768-1024 / desktop >1024） |
| `useTheme` | 主题切换 |
| `useTimers` | 倒计时（验证码发送等） |
| `useBodyScrollLock` | 弹窗打开时锁 body 滚动 |

## 6. 公共组件（`components/`）

| 组件 | 用途 |
|------|------|
| `ClickCaptcha` | 点选验证码（对接后端 generate/verify） |
| `DictTag` | 字典值标签渲染 |
| `FormDialog` | 表单弹窗（小屏自动 92% 宽） |
| `ImagePicker` | 图片选择（含 logic.ts 抽离） |
| `MobileAction` | 小屏折叠操作按钮（含 logic.ts，配 responsive 断点） |
| `Pagination` | 分页 |
| `WangEditor` | 富文本（内容经 sanitize 净化） |
| `ResponsiveTable` | 响应式表格（logic.ts + types.ts，小屏横向滚动） |
| `CollapsibleFilter` | 可折叠搜索栏 |

## 7. 响应式规范（规则 11）

- 搜索栏 `el-row` + `el-col` 断点（`:xs="24" :sm="12" :md="8" :lg="6"`）；
- 统计卡片 `:xs="24" :sm="12" :md="6"`；
- 表格小屏横向滚动；弹窗 <768px 自动 92% 宽；
- 操作列小屏用 `MobileAction` 折叠；侧边栏移动端自动折叠为图标；
- mixin 在 `assets/styles/responsive.scss`。

## 8. 视图（`views/`）

- `login/`（含协议展示、验证码）、`dashboard/`；
- `system/`：user、role、menu、dept、post、config、dict、log、file 共 9 个 `index.vue`；
- `payment/`：订单列表 `index.vue`、`create.vue`；
- `member/`：`index.vue`（会员）、`level.vue`、`tag.vue`、`points.vue`；
- `settings/`：site、payment、oss、sms、agreement（对应 `sys_config` 的 `FindByPrefix` 分组）；
- `error/404.vue`。

## 9. 安全

- Token 存 Cookie（`sameSite: Lax` + HTTPS 时 `secure`）；
- **无 `v-html` / `innerHTML`**；DOMPurify + `utils/sanitize.ts` 净化；
- 所有写请求自动带 CSRF 头。

## 10. 构建与测试门禁

```bash
npm run dev          # Vite 开发服务器
npm run build        # vue-tsc（类型检查）→ vite build → scripts/check-bundle.mjs（体积门禁）
npm run typecheck    # vue-tsc --noEmit
npm run lint         # eslint . --max-warnings 0（警告即失败）
npm run test         # vitest run（*.spec.ts 与源码同目录）
npm run format:check # prettier
```

**三重构建门禁**：类型检查（vue-tsc）→ 严格 lint（0 警告）→ bundle 体积检查（`check-bundle.mjs`），任一失败即构建失败。CI 中 `make check-frontend` 调用同套检查。
