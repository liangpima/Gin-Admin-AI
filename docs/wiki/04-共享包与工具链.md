# 04 - 共享包与工具链

## 1. `pkg/` 共享包

依赖方向铁律：**`pkg/` 不依赖 `internal/`**。需要注入内部能力时用回调（如 `task.SetPanicHandler` 由 main.go 注入 zap）。

### 1.1 `pkg/auth` — JWT

| 函数 | 说明 |
|------|------|
| `GenerateAccessToken(userID, username, tenantID, deptID)` | 签发 access token（2 小时），issuer = `go-admin` |
| `GenerateRefreshToken(...)` | 签发 refresh token（7 天），issuer = `go-admin-refresh` |
| `ParseToken(s)` | 只接受 access issuer，拒绝 refresh（防止混用） |
| `ParseRefreshToken(s)` | 只接受 refresh issuer |

Secret 来自 `config.jwt.secret`（环境变量 `JWT_SECRET` 优先）；生产默认值拒绝启动。

### 1.2 `pkg/upload` — 多端文件上传

- **接口抽象**：`uploader`（Upload/Delete/GetURL），实现 `local`（本地）、`aliyun_oss`、`tencent_cos`、`minio`；
- `Init(cfgMap)`：启动时从 `sys_config` 的 `oss.*` 配置自动选择存储方式；`Reload` 支持配置热更新（config_service 保存后触发）；
- `SetAllowedExts(csv)`：白名单注入（来自 `upload.allow_exts`）；`dangerousExts` 硬编码黑名单（php/exe/sh/bat/js/vbs 等）**始终生效**；
- `ValidateFile(filename)`：扩展名校验；`Upload/UploadContext/UploadWithContext`、`Delete/DeleteContext`、`GetURL`；
- `/uploads` 为匿名可读目录，由 `middleware.UploadSecurity` 补 CSP 头；**密钥/证书类禁止存放**（证书走 `runtime/certs/`）。

### 1.3 `pkg/excel` — Excel 导入导出

`NewExporter(sheetName)` → `SetHeaders` → `AddRow` → `WriteToWriter`/`SaveAs` → `Close`。基于 excelize，用户导出等接口使用。

### 1.4 `pkg/task` — 定时任务

- `Init / AddJob(spec, cmd) / Start / Stop`；
- **`AddJob` 自动包一层 recover**：robfig/cron 默认不 recover，任务 panic 会直接终止整个进程，而 HTTP 的 `Recovery` 中间件救不了后台任务；
- `SetPanicHandler(fn)`：panic 上报函数由 main.go 注入 zap。

当前注册任务：日志清理（每天 03:00，10 分钟超时）→ `logService.CleanExpiredLogs`。

### 1.5 `pkg/utils` — 工具函数

| 文件 | 函数 |
|------|------|
| `hash.go` | `HashPassword`（bcrypt）/ `CheckPassword` |
| `string.go` | `RandomString` / `Contains` / `RemoveDuplicates` / `CamelToSnake` |
| `snowflake.go` | `InitSnowflake(machineID)` / `GenerateID()` — 分布式 ID |

### 1.6 `pkg/httpx` — HTTP 客户端

`NewClient(timeout)` → `Do(ctx, method, url, body, header)` / `DoJSON` / `DoForm`。支付网关请求的基础客户端。

### 1.7 `pkg/sanitize` — HTML 净化

`RichText(input)`：基于 bluemonday 白名单策略，清洗富文本（WangEditor 内容入库/出库防 XSS）。

## 2. `cmd/` 工具

### 2.1 `cmd/gen` — 业务模块脚手架生成器

```bash
go run ./cmd/gen -name <模块名> -title <中文名>
```

一次性生成：

- `internal/module/<名>/` 的 model/repository/service/controller/dto 骨架；
- `sql/migrations/` 幂等建表迁移（`CREATE TABLE IF NOT EXISTS`）；
- 自动把权限码与路由注册插入 `router/router.go` 的 **4 处 `gen:` 锚点**（锚点注释被删会报错拒绝执行，需恢复锚点而非绕过）；
- 生成后自动跑 `go build` 与 `swag init` 自检。

生成后仍需手工：改字段（model/迁移/init.sql 三处同步）、跑迁移、挂菜单（含 `sys_menu` type=2 按钮记录）、实测 200/403。

### 2.2 `cmd/migrate` — 迁移工具

```bash
go run ./cmd/migrate            # 按文件名顺序应用 sql/migrations 下的 .sql（跳过 .down.sql）
go run ./cmd/migrate -status    # 查看迁移状态
```

迁移文件幂等；`Makefile` 提供 `migrate` / `migrate-status` 目标。`scripts/check-migrations.sh` 在 CI 中校验迁移规范。

### 2.3 `cmd/server` — 服务入口

启动链详见 [01-项目整体架构.md](./01-项目整体架构.md) §4。

## 3. Makefile 目标

| 目标 | 说明 |
|------|------|
| `build` / `run` / `clean` | 编译 / 运行 / 清理 |
| `test` / `coverage` | 测试 / 覆盖率（CI 门槛约 74%） |
| `lint` | 静态检查（gofmt/vet 等） |
| `check` | **总门禁** = check-backend + check-frontend + check-deploy + check-migrations + check-secrets |
| `check-race` | `-race` 竞态检测 |
| `check-vuln` | govulncheck 漏洞扫描 |
| `check-secrets` | gitleaks 密钥泄漏扫描 |
| `migrate` / `migrate-status` | 迁移执行 / 状态 |
| `swagger` / `swagger-baseline` | 生成 Swagger / 与基线一致性比对（CI 检查文档是否过期） |
| `deps` | go mod tidy |

## 4. 测试结构

- 单元测试与源码同目录（`*_test.go`），含大量**语义约束测试**：`error_semantics_test.go`（错误语义）、`layering_test.go`（分层约束）、`service_tx_db_test.go`（事务）、`login_guard_test.go`（限频）、`idempotency_test.go`、`csrf_test.go` 等；
- `internal/conventions`：架构铁律的机械校验；
- `internal/testsupport`：测试基建；
- 前端 vitest 测试与源码同目录（`*.spec.ts`）。
